# Security policy

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/MindLink-ApS/bitsov-app/security/advisories/new)
to send a report to the maintainers. If that option is unavailable, email
[info@mindlink.tech](mailto:info@mindlink.tech) to arrange private reporting.
Email is a fallback contact channel, not a promise of encrypted transport.

Do not open a public issue or pull request containing vulnerability details.
In a private report, include the affected version or commit, platform, impact
and reproduction steps. Remove recovery phrases, private keys, tokens,
personal information and details of other people's infrastructure.

## Supported versions

BitSov is a signet-only beta, currently version `0.0.1`. Security fixes target
the current beta code on `main`. Earlier snapshots and development branches
are not maintained as separate supported versions. There is no stable or
long-term-support release yet.
